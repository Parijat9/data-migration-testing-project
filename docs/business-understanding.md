# Business Understanding

## What is data migration?
Data migration means moving data from one system to another.

## Why is the client doing this?
The client moved data from System A to System B because they want to use a new system.

## Why does accuracy matter?
Accuracy matters because if the migrated data is wrong, the new system will also give wrong results.

## Risks if data is wrong
- Missing records
- Wrong customer details
- Wrong order information
- Incorrect reports
- Business process failures

## Why test the migration?
Testing helps confirm that important data moved correctly and that transformation rules were applied properly.
