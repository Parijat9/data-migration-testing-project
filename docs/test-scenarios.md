# Test Scenarios

## Scenario 1
Verify that total number of records in source and target match.

## Scenario 2
Verify that all expected columns exist in the target file.

## Scenario 3
Verify that important fields are not blank.

## Scenario 4
Verify that unique fields do not contain duplicate values.

## Scenario 5
Verify that transformation rules were applied correctly.

## Scenario 6
Verify that totals and important values match expected results.
